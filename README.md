# Marvel App

A simple Marvel-themed Flutter application built with Dart and Flutter.

##  Full Project Structure

```text
marvel_app/
├── android/
├── ios/
├── lib/
│   └── main.dart
├── test/
├── web/
├── windows/
├── macos/
├── linux/
├── pubspec.yaml
└── README.md
```

The `main.dart` file from this repository should be placed inside the `lib/` folder of a Flutter project.

##  How to Run

### 1. Create a Flutter project

Make sure Flutter is installed, then run:

```bash
flutter create marvel_app
```

### 2. Replace `main.dart`

Go to:

```text
marvel_app/lib/main.dart
```

Replace the existing `main.dart` with the `main.dart` file from this repository.

### 3. Run the app

Open a terminal inside the project folder and run:

```bash
flutter run
```
